# katibehTahrir – قالب فروشگاه لوازم‌التحریر وردپرس

یک قالب حرفه‌ای برای فروشگاه‌های لوازم‌التحریر، ساخته‌شده بر پایه **Astra (نسخه رایگان)** با پشتیبانی کامل از **WooCommerce** و **Advanced Custom Fields (ACF)**.  
این قالب دارای یک سیستم اختصاصی برای **ایمپورت محصولات** از سایت‌ها یا فایل‌های اکسل است و کاملاً بدون نیاز به نسخه‌های پرو کار می‌کند.

# 🔧 نصب و راه‌اندازی قالب

1. آپلود پوشه قالب در مسیر:  
   `wp-content/themes/`
2. فعال‌سازی قالب از پیشخوان وردپرس
3. نصب و فعال‌سازی افزونه‌های مورد نیاز
4. تنظیمات فروشگاه در ووکامرس
5. پیکربندی فیلدهای ACF (اتوماتیک از acf-json)
6. استفاده از منوی **Tools > Import Products** جهت ایمپورت محصولات

# 📂 معرفی پوشه import-products

پوشه **import-products** شامل یک سیستم اختصاصی برای وارد کردن انبوه محصولات به ووکامرس است.

## ✨ قابلیت‌های اصلی سیستم ایمپورت

- خواندن فایل‌های اکسل (XLSX)
- بررسی و پاکسازی داده‌ها
- ایمپورت گروهی یا تکی محصولات
- بروزرسانی خودکار محصولات موجود
- دانلود و الصاق تصاویر از URL
- ساخت خودکار دسته‌بندی‌ها، ویژگی‌ها و برچسب‌ها
- پشتیبانی از محصولات ساده و متغیر
- ارائه گزارش کامل پس از ایمپورت

## 🔄 روند کارکرد سیستم

1. کاربر فایل اکسل را آپلود می‌کند  
2. سیستم داده‌ها را بررسی و خطاها را گزارش می‌دهد  
3. عملیات ایمپورت آغاز شده و محصولات به ووکامرس اضافه می‌شوند  
4. گزارش نهایی نمایش داده می‌شود  

این سیستم مناسب **انتقال فروشگاه‌های قدیمی** یا **وارد کردن محصولات از تأمین‌کنندگان** می‌باشد.

# 🔧 Installation

1. Upload the theme to:  
   `wp-content/themes/`
2. Activate the theme from WordPress admin
3. Install the required plugins
4. Configure WooCommerce settings
5. ACF fields auto-load from acf-json
6. Use **Tools > Import Products** to import products

# 📂 import-products Folder Description

This folder contains a complete system for bulk-importing products into WooCommerce.

## ✨ Main Functions

- Reads Excel (XLSX) product files  
- Validates and cleans input data  
- Bulk or single product import  
- Updates existing products automatically  
- Downloads and attaches images from URLs  
- Creates categories, attributes, and tags automatically  
- Supports simple and variable products  
- Generates a full import report  

## 🔄 Workflow

1. User uploads Excel file  
2. Data is validated  
3. Import process begins  
4. Final report is displayed  

Ideal for **migrating old stores** or **importing supplier product lists**.
